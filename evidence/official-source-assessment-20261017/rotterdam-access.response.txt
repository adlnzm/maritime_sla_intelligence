Request a guest account from your Port of Rotterdam contact to gain access.</p><p>Once you have an account, click the sign-in button to log in with single sign-on.</p><p>In the API overview, you will find our available APIs. The products can be found on the API products page. An API product contains one or more APIs. To gain access to an API, you need a subscription key. Follow these steps to obtain a subscription key:</p><ol><li><p>Go to the desired API product.</p></li><li><p>Enter a name for your subscription. This name will also be displayed on your profile page.</p></li><li><p>Click the Subscribe button to submit the request. You will receive a confirmation email.</p></li><li><p>The owner of the API will review your request. You will be notified by email as soon as possible.</p></li><li><p>After approval, you can find the subscription key on your profile page.</p></li><li><p>Add the subscription key as header parameter for your API request.
