## Exact sources, fields and access

### IMF PortWatch

- [Platform](https://portwatch.imf.org/); [daily dataset item](https://www.arcgis.com/sharing/rest/content/items/83b1bbc7b3354c5fb1f40673bb8f852e?f=json); [actual layer](https://services9.arcgis.com/weJ1QsnbMYJlCHdG/arcgis/rest/services/Daily_Ports_Data/FeatureServer/0?f=pjson); [query endpoint](https://services9.arcgis.com/weJ1QsnbMYJlCHdG/arcgis/rest/services/Daily_Ports_Data/FeatureServer/0/query); [port reference layer](https://services9.arcgis.com/weJ1QsnbMYJlCHdG/arcgis/rest/services/PortWatch_ports_database/FeatureServer/0?f=pjson).
- Official item description defines entering a port boundary as a call, with filtering for short turnaround/no draft change. Tonnage comes from vessel/payload estimates. Fields include `portid`, `portname`, UTC `date`, `portcalls` and category counts, `import`, `export`. ArcGIS date field is UTC; date is not acquisition time. AIS reception, transmission gaps and self-reporting limit completeness. Do not interpret calls as measured congestion duration.
- Retained authority/proof: `../freshness-diagnosis-20261017-131acd0c/arcgis-item.json`, `layer-metadata.json`, six `latest-port*.json` responses and `diagnosis.json`. Item is public and points to the configured service. Layer advertises `maxRecordCount=1000`, pagination support and query-only capabilities; this is a page-size limit, not a request-rate SLA. Auth not needed for these successful public requests. Numeric rate quota not established: retain bounded retries and 429 handling.
- Item licenses via [IMF terms](https://www.imf.org/external/terms.htm); terms page returned 403 through browsing during this assessment. Production/redistribution permission remains unverified, not an inferred open license. Attribute IMF PortWatch and the methodology: [Tracking Trade from Space](https://www.imf.org/en/Publications/WP/Issues/2021/08/20/Tracking-Trade-from-Space-An-Application-to-Pacific-Island-Countries-464345). Platform describes daily data since 2019; per-port historical completeness was not newly enumerated here.

August 2026 monthly count 0 proves only this exact query lacked rows.

Registered free tier documented at 500 requests/day, one request/second, up to 100,000 records/call; premium limits differ. Do not assume guest preview inherits registered limits. Use key in secret storage for supported registered access. Repository contains no new key.
- Portal has United Nations copyright and a License Agreement link. Full license text could not be obtained in this pass; attribution/redistribution rights need verification before commercial reuse. National reports, estimates, revisions and aggregate flags require preservation. Country/commodity trade cannot establish port-specific arrival/waiting or commercial SLA outcome labels.

## Evidence and recommendation

Public API probes initially failed sandbox DNS; approved public network execution produced 200 (Comtrade empty month), 401 (WTO key required), 429 (Comtrade), then 200 (annual retry). Script process exits were zero because HTTP failures were deliberately captured as data; **zero process exit is not API success**. URLs, UTC retrieval timestamps, body SHA-256 and HTTP status are in `international-access.json`; bodies contain no credentials. Official-page research used the linked documents; inaccessible/undemonstrated licenses and newest records are explicitly unresolved.

Keep PortWatch primary for its declared daily activity metric, with six independent unchanged 10-day checks. Separately qualify port-authority feeds for corroboration with explicit scope, event semantics and source-specific contracts. Keep trade/tariff and geopolitical indicators in contextual tables with their own periods and classification; never fill missing port observations with them. Before adding any candidate, review its rights, verify several small real responses, establish identifiers/coverage/cadence, and add source-specific tests for periods, estimates, revisions, missing rows, auth and rate-limit failures. This research supplies no live shipment-SLA training labels and changes no release acceptance claim.
