## Rights decision and smallest next step

[UN policy](https://uncomtrade.org/docs/policy-on-comtrade-data-use/) permits internal institutional use, requires UN Comtrade attribution and applies its licence to free and premium access. The owner’s external/mixed audience does not meet the internal-only definition. API availability alone does not authorize product distribution.

The [specific redistribution guidance](https://uncomtrade.org/docs/re-dissemination-of-data/) provides exceptions for limited tables, free visualization and small extraction services. It also says commercial redistribution below 100,000 total product/database records needs no extra licence, while other sections require a distribution licence for paid applications and disagree about premium subscription necessity. The threshold is total stored/distributed records, not each request. This is an unresolved applicability conflict, not evidence that all external use is forbidden. Reformatting is not substantial transformation. We have not established a permitted scope for this mixed-audience product or assumed that a small API batch resolves it.

Smallest next step: owner/licensing contact should ask `subscriptions@un.org` to confirm, in writing, the applicable exception or licence for a bounded national-trade context table exposed in platform reports/API/Power BI, including whether access is charged, total retained records including versions, exports, downstream redistribution, attribution, refresh and archival retention. Refer specifically to the conflicting commercial-small-dataset and paid-application sections. This is a prepared request scope, **not a message sent**. A free, narrowly bounded public visualization may qualify; confirm that it is actually the intended product before implementing that restriction.

[WTO general copyright](https://www.wto.org/english/info_e/copyrights_permissions_e.htm) distinguishes unrestricted official documents from other material and requires written permission for commercial website-material use. [TTD terms](https://ttd.wto.org/download-static/terms-of-use) separately restrict reuse and mass download; do not extend one product's permission to another. Obtain the relevant indicator/product licence and key, then one bounded actual row plus metadata. No account, key, subscription or permission was invented or added to files.

## Data lineage and reviewable implementation boundary

Current: IMF raw response + checksum/retrieval metadata → source-date normalization → separate daily port activity → six independent observation-age checks (10 days) → governed operational outputs. Source activity retains declared classifications; computed stress is DERIVED, expected events ANTICIPATED, synthetic scenarios SIMULATED, forecasts PREDICTED. Activity is not observed waiting time, and reference lanes are not observed vessel tracks.

Proposed only, **not implemented**: authorized WTO/Comtrade raw response → separate versioned trade-context dataset keyed by provider/dataset/reporter/partner/commodity/flow/frequency/period → contextual report panel. Retain period start/end, native units, geography, publication/revision time or explicit absence, acquisition UTC, flags, attribution/licence and raw hash. Link to operational views only through explicitly labelled country/period context; never insert trade rows into port activity or fill missing port observations. US national statistics cannot be allocated to LA/LB versus NY/NJ without independent port data.

After rights and metadata qualification, implement a bounded opt-in adapter with one allowlisted endpoint, finite response/record limits, timeout and bounded Retry-After handling, no secret logging, immutable revision identities and a product-wide retained-record ceiling where required. Add tests for malformed/HTML responses, empty results, missing periods, annual/monthly boundaries, future/stale periods, timezone-aware acquisition, revisions/replay, nulls/estimates, 401/403/429 and exhausted retries. These are acceptance requirements for a future adapter, **not tests claimed to exist now**.
